# Dnier

A simple, full-featured GitHub workspace for desktop and mobile.

## MVP v0.1

- GitHub-oriented workspace UI
- Repository list and search
- Repository file browser
- Branch selector UI
- File editor UI
- Repository download entry point
- New file / repository action entry points
- Responsive desktop and mobile layouts

## Development

```bash
npm install
npm run dev
```

The first version uses local demo data for the interface. GitHub OAuth and live GitHub API integration are the next step.
